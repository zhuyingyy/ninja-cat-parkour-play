## 替换步骤

1. 在 Figma 的 05 / Motion 中替换同名 PNG，保留框尺寸，按每项已设置的 1× / 2× / 4× 导出。
2. 覆盖项目 `assets/motion/` 对应文件，刷新网页。Figma 导出不会自动同步本地文件。
3. 跑步速度在 `config.js` 的 `assets.run.fps`；背景各层速度在 `parallax`。

本目录共有 **12 张 PNG**；运动素材包另外包含两张 `assets/png/` 下的站立待机 PNG。完整素材清单和节点编号在上一级 `manifest.json`；生成模式和完整提示词在本目录 `GENERATION.md`。

本次 P 字头巾编辑的提示词见 `HEADBAND-P.md`。待机、跳跃和头像也已同步，位于 `assets/png/`，在完整 PNG 素材包内。

## 天空樱花效果

天空上叠加独立透明 Canvas 花瓣层，位于场景和障碍物上方、小猫下方，HUD 仍在最上层。默认 28 片更大、更清晰的粉色像素花瓣，下落、轻摆和翻转；暂停时冻结，系统开启减少动态效果时隐藏。它是代码绘制的装饰效果，不需要新增 PNG。

`config.js` 中的 `sakura.enabled` 控制开关，`sakura.count` 控制数量（上限 80），`sakura.speed` 控制飘动速度（默认 1.25）。近景樱花树继续从 Figma 节点 357:856 导出并替换同名 `scenery.png`。

## 奔跑脚后烟尘

小猫贴地奔跑时，每 0.15 秒在后脚外侧产生一团清晰的灰白像素烟尘，位于樱花上方、小猫下方。烟尘向后漂移、轻微上升并在约 0.8 秒内淡出，向后漂移速度低于地面，使烟尘在屏内形成连续短尾迹；跳跃与结算时停止产生，已有烟尘自然消散。暂停冻结烟尘，重开清空；减少动态效果模式下关闭。效果由代码绘制，不新增美术切图。

## 站立待机与开始提示

开始前读取两张 928 × 664 透明 PNG：`cat-idle.png` 睁眼、`cat-idle-blink.png` 眨眼，脚底基线均为 y=659。显示尺寸仍为 232 × 166。待机时轻微呼吸、偶尔眨眼并摆动头巾，背景与地面保持不动，不产生脚后烟尘。开启减少动态效果时角色静止。

小猫上方提示「准备好了吗？」，按钮上方提示「点击开始冒险」。按 JUMP 开始后立即隐藏提示，恢复六帧奔跑、背景滚动与烟尘。新 PNG 已置于 Figma 的 05 / Motion，4× 独立导出。
